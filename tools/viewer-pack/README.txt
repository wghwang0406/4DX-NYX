NYX 뷰어 서버 (사내 서버 PC 용)
================================

필요한 것: Node.js 22.5 이상 (https://nodejs.org 의 LTS). 저장소·pnpm 은 필요 없습니다.

켜기
  맥     start.command 더블클릭 (처음엔 우클릭 → 열기)
  윈도우 start.bat 더블클릭
  터미널 node start.mjs

처음 켜면 게시 토큰을 만들어 nyx-viewer.env 에 저장하고, 이 PC 의 사내 IP 주소를 터미널에 보여줍니다.
  - 다른 PC 브라우저에서 그 주소(http://192.168.x.x:8787/)를 열면 현황 화면 — 토큰을 넣으면 게시된 판 목록이 보입니다.
  - 스튜디오(NYX 앱) › 설정 › 게시 서버에 같은 주소와 토큰을 넣고 [연결 확인] → Publish 에서 게시.
  - 리뷰어는 게시 때 나온 링크(/r/…)로 들어가 코멘트를 남깁니다.

게시 전에는 서버에 아무것도 없습니다 — 현황 화면에 "아직 게시된 콘티가 없습니다"가 나오면 정상입니다.

데이터: 옆 data/ 폴더 (코멘트 DB + 게시 파일). 백업은 이 폴더 하나.
Dropbox 보관(선택): nyx-viewer.env 에 DROPBOX_TOKEN=… 을 넣고 다시 켭니다.
방화벽: 8787 포트를 사내망에 열어 주세요. 이 PC 가 꺼지면 링크도 열리지 않습니다.
