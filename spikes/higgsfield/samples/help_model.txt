List Higgsfield models and inspect each model's job_type, media type, and accepted parameters.

Usage:
  higgsfield model [command]

Examples:
  higgsfield model list
  higgsfield model list --image
  higgsfield model get nano_banana_2

Available Commands:
  get         Show model parameters and defaults
  list        List image, video, text, and audio generation models

Flags:
  -h, --help   help for model

Global Flags:
      --json       print raw JSON responses
      --no-color   disable color output

Use "higgsfield model [command] --help" for more information about a command.
